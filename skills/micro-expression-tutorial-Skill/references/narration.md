# 口播写法 · 说人话

> 口播不是把幻灯稿念一遍，是**另一种节奏的讲解**。
> 目标是：只听声音也能跟下来；看画面能对上号。

---

## 一、三条不可违反的规则

### 1. 不讲过程

**删**：
- 「我们试了 N 版才…」「第一版出来像…，后来才发现…」
- 「这里有 8 版迭代，每一版只动一处」
- 「结论来自 8 版实测与 18 张真人参考图」
- 「你不需要知道我们试了多少版」

**换成**：现象 → 原因 → 做法。
例：
> ❌ 「我们第一版出来像晒伤，后来改成机制句才把浓度降下来。」
> ✅ 「情绪形容词推不动颜色，机制句可以。写成 faint、soft、delicate，数值不降反升；写成皮肤原色加一点点血，彩度增量降了百分之二十八。」

### 2. 不出现版本号

口播里说**现象名**，不说「第几版」。
> 「愤怒的面红耳赤，整脸一片红、烧到脖子下巴。」而不是「V3 那样」。

### 3. 数字用读出来的形式

口播脚本里，数字直接写成**读法**，TTS 就不用猜：

| 屏上（`text`） | 口播（`text` / `say`） |
|---|---|
| `+4.00` | `四点零` |
| `−2.15 ~ +10.90` | `负二点一五到正十点九` |
| `65%` | `百分之六十五` |
| `−28%` | `降了百分之二十八` |
| `5°~15°` | `五到十五度` |

如果屏上要保留阿拉伯数字而读法不同，用 `clauses[].say`：
`text` 负责上字幕，`say` 负责被念出来，**`say` 永远不进字幕**。

## 二、一页几句

- 一页 **2~4 句**，每句一个意思。
- 每句 **≤ 60 字符**（超过会折 3 行字幕，可读性差；`plan-timings` 会警告）。
- 一句只带**一个**数字或**一个**结论。句子里塞两个数字，观众就只记住一个。
- **句尾要有终止标点**（`。！？`）。不接标点时 TTS 不会停顿 —— 拼句时补 `，`。

### 句与画面的对应

`clauses[].stage` 决定这句话开口时哪一层入场。

```
clauses: [ {stage:1, text:"整套方法就四步。"},
           {stage:2, text:"量真人，定出带子，把量翻译成提示词，生成完再验。"} ]
```
- stage 1 → 标题层
- stage 2 → 流程卡片层

**强同步**：讲「大数字」的那一句，那个数字就要在那句开口时出现。

## 三、字数与时长

时长由 **ffprobe 实测**决定，不靠估算。经验值：

| 音色 | speed | 字/秒 | 1220 字 ≈ |
|---|---|---|---|
| 默认男声 `male-qn-qingse` | 1.10 | ~5.3 | 3 分 50 秒 |
| `Chinese (Mandarin)_Wise_Women` | 1.10 | ~4.3 | 4 分 45 秒 |
| `Chinese (Mandarin)_Sweet_Lady` | 1.10 | ~4.2 | 4 分 50 秒 |

**女声比男声慢约 20%** —— 同样字数，成片更长。这是选型时要知道的事，不是 bug。

如果成片嫌长，**优先删句子**，不要猛提 speed（提快之后中文的可懂度掉得很快）。

## 四、语气的几条经验

| 场景 | 写法 |
|---|---|
| 讲清一个反直觉的结论 | 先给结论，再给反例：「情绪形容词推不动颜色，机制句可以。」 |
| 讲一个必须记住的口诀 | 短句 + 停顿：「色度轴记住一句：只加血，不压暗。」 |
| 讲一条不能破的纪律 | 用「别」+ 具体后果：「别点名部位 —— 模型会把那里也染红。」 |
| 收尾 | 给可执行的下一步，不是感想：「找五张参考图，每张框两块，量出你的带子。」 |

**别用**：「我们可以看到」「不难发现」「显而易见」「众所周知」——
这些词在口播里全是噪音，删掉句子反而更短。

## 五、TTS 前的音色选择

**必须试听 + ASR 反查**，不能靠名字判断：

1. `get_voice_list` 拉全量音色（本项目实测 327 个）。
2. 筛出语种匹配的（中文用 `Chinese (Mandarin)_*`）。
3. 挑 3~4 个候选 + 首选音色的三档语速，各合成**一句**试听。
4. **ASR 反查每一条**（`upload_temp_url` + `listen_audio`）：确认是**普通话简体**、
   数字读对。已知的坑：`Chinese (Mandarin)_News_Anchor` 名字写普通话，**实际输出粤语**。

> 反查不只是查语种：数字听错（"机线" 其实是"极线"）说明是 ASR 的错，不是合成的错，
> 但要逐条核，别把 ASR 误差当成 TTS 误差去重做。

## 六、`script.json` 里与口播相关的字段

```json
{
  "lang": "zh",
  "voice": "Chinese (Mandarin)_Wise_Women",
  "speed": { "default": 1.1, "first": 1.05, "last": 1.05 },
  "slides": [{
    "id": "05", "layout": "chart", "html": "05-band.html", "audio": "05.mp3", "title": "",
    "clauses": [
      { "stage": 1, "text": "没有带子，所有差不多都是自我感觉。" },
      { "stage": 2, "text": "真人害羞红的彩度增量，中位是四点零，带子从负二点一五到正十点九。" }
    ]
  }]
}
```

- `speed.first/last`：首末张放慢 0.05，收尾更稳。
- **短句（≤10 字）不要放慢** —— 慢速读短句会显得拖沓。
- `audio` 文件名与 `id` 对应，落在 `project/audio/`。
- 一页一段音频（**不是一句一段**）；`plan-timings` 按字数把整段拆成逐句时刻。

## 一、事实底稿的写法

`project/research/notes.md` 是**唯一**的数字来源。每条记三样：

```
- 数字 / 结论
- 出处文件（+ 行号或 key）
```

## 二、测量口径铁律

### 1. 基准按主体自身肤色归一化

跨肤色人群的**绝对色带**（H/S/R−B）不能当基准。
一切量都是「红晕区 减 同脸基线区」。

### 2. 基线必须同一受光面

多光源场景里额头与两颊不在同一光照平面。
拿暗侧皮肤去比受光脸颊 → ΔL\* 把打光差异算成脸色差异 → **整条带子作废**。

### 3. 基线质量门（三条）

| 门 | 阈值 | 挡掉什么 |
|---|---|---|
| 不能太暗 | L\* > 25 | 基线落进深阴影（测的是黑，不是肤色） |
| 同一光照平面 | \|ΔL\*\| ≤ 12 | 打光差异混进脸色差异 |
| 必须是皮肤 | 人工判 | 框到头发、衣服、背景 |

### 4. 视频侧要逐帧手工框

**固定框在推近镜头下必然漂移** → 取样框跑到背景上 → 数值全错。
对策：首帧 / 末帧各手画一次，中间帧**线性插值**；每条曲线都要回绘目视校验。

### 5. 跨版本比浓度用 C\*，不用 S

HSL 的 S 随明度剧烈变化（高 L 放大 S、低 L 虚高 S）。
跨版本比浓度一律用 CIELAB 的彩度 C\*。

## 三、真人害羞红的数值带（可直接上台面）

**两步筛选，别混成一步**：

```
18 张手工框定样本
  └─ ① 基线质量门 → 过门 9 张 / 剔除 9 张
       剔除原因：8 张两区域受光面不匹配（|ΔL*| 14.4~43.3）、1 张基线落深阴影（L*=2.0）
  └─ ② 只在过门的 9 张里按「红的成因」分类
       生理性/情绪性脸红 n=4   ← 数值带只由这 4 张量出
       病理·上限型     n=2
       对照组           n=3
```

| 量 | 含义 | 范围 | 中位 |
|---|---|---|---|
| **ΔC\*** | 彩度增量（红晕区 − 同脸基线） | −2.15 ~ +10.90 | **+4.00** |
| **Δa\*** | 血色增量 | −4.66 ~ +18.91 | +4.78 |
| **ΔL\*** | 明度增量 | −11.38 ~ +0.72 | −4.73 |
| **S 比** | 饱和度比（红晕区 / 基线） | 1.00 ~ 2.34 | 1.16 |
| **V 比** | 明度比（红晕区 / 基线） | 0.86 ~ 1.19 | **0.99** |

### 两条指纹（教程的高光）

1. **V 比 ≈ 1** → 害羞红**不改变皮肤明度**，只是皮下多了血。
   脸发暗、发灰是**缺陷**，不是「更浓」。
2. **Δa\* > 0** → 只加血色，同时彩度小幅上升。

### 第二判据源（用来排硬伤，不是用来定带）

外部方法论文档给的区间更紧（H 5~15°、S 15~35%），与我们自测的真人带（S 20.4~55.6%）
不完全重合。**按更紧的带子调，会调出「符合数字但发灰」的结果。**

> 结论：**数值带只用来排硬伤**（色相跑带 / 嘴唇被误改 / 明度被压暗），
> 好不好看是审美终审，不要拿数字达标冒充好看。

## 四、可以上台面的「实测结论」

这些是**方法本身**，不是过程，可以直接进片：

| 结论 | 数字 | 怎么讲 |
|---|---|---|
| 情绪形容词推不动颜色 | 彩度增量不降反升 | 「写成 faint、soft、delicate，数值不降反升」 |
| 机制句有效 | ΔC\* −28% | 「写成皮肤原色加一点点血，彩度增量降了百分之二十八」 |
| 色词替换有效 | 彩度 +0.53 | 「pale/milky/seashell → clear/warm/rose-pink，同一诉求差 0.53」 |
| 「淡」= 彩度轴 | ΔC\* 增量减半 | 「淡不是自由参数，稀释目标才是」 |
| 稀释目标不能低于局部皮肤彩度 | — | 「目标 = 局部自然彩度 + 一点点血色，永远不低于周围皮肤」 |
| 锁首帧才能从零升起 | 首帧已是峰值 65% | 「纯文生视频第一帧就带着红晕，首帧强度已是峰值的百分之六十五」 |

**不要上台面的**：版本号、每版改了什么、返工次数、「我们试了几次」。

## 六、素材搜集的坑

- Wikimedia 全域与多数图床在沙箱里**不可达**；`images.weserv.nl` 可作图片代理。
- pexels / pixabay 直连 403。
- 面部特写容易触发误判（框到眉毛、头发）→ 人工复核每一张。
- 搜索结果里的「图说」不等于真实病因（同一张图常被标成「愤怒」其实在运动）→
  **成因分类要靠自测的 Δa\*/ΔL\*/V 比，不能靠图说**。
